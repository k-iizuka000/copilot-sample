# Quality Gate コマンド

ファイルまたはプロジェクト範囲に対して、必要に応じて ECC 品質パイプラインを実行します。

## 使用方法

`/quality-gate [path|.] [--fix] [--strict]`

- デフォルト対象: 現在のディレクトリ（`.`）
- `--fix`: 設定されている場合、自動フォーマット/修正を許可
- `--strict`: サポートされている場合、警告で失敗させる

## パイプライン

1. 対象の言語/ツールを検出する。
2. フォーマッタチェックを実行する。
3. 利用可能な場合は lint/型チェックを実行する。
4. 簡潔な修正リストを生成する。

## 注意事項

このコマンドは hook の動作を反映しますが、オペレーターが明示的に呼び出します。

## 引数

$ARGUMENTS:
- `[path|.]` 任意の対象パス
- `--fix` 任意
- `--strict` 任意
