## エージェント標準項目テンプレート

| 項目                         | 必須 | 内容                                                        |
| -------------------------- | -: | --------------------------------------------------------- |
| `agent_name`               | 必須 | エージェント名。役割が一目で分かる名前。例: `requirements-planner-agent`       |
| `purpose`                  | 必須 | このエージェントが存在する目的。何を改善・自動化・評価するための担当か                       |
| `role`                     | 必須 | 担当役割。例: 要件整理、設計レビュー、実装計画、検証、リスク評価                         |
| `non_role`                 | 必須 | 担当しないこと。越権防止用                                             |
| `trigger`                  | 必須 | どんな依頼・状況で使うか                                              |
| `user_questions`           | 必須 | 作成時にユーザーへ必ず確認する質問                                         |
| `input_contract`           | 必須 | 入力として必要な情報。目的、背景、対象範囲、制約、成果物、成功条件など                       |
| `output_contract`          | 必須 | 出力形式。Markdown / JSON / checklist / plan / diff summary など |
| `output_schema`            | 推奨 | 出力を機械検証したい場合の JSON Schema または固定見出し                        |
| `success_conditions`       | 必須 | 完了・成功の判定条件                                                |
| `failure_conditions`       | 必須 | 失敗・未完了・保留にすべき条件                                           |
| `verification`             | 必須 | 出力後に何を確認するか。例: 必須項目充足、矛盾、検証不能、リスク                         |
| `completion_status`        | 必須 | `success` / `failure` / `unverified` の3値で完了判定             |
| `allowed_tools`            | 必須 | 使用してよいツール・機能。Copilot IDE前提なら IDE 内で使える範囲に限定               |
| `disallowed_tools`         | 必須 | 使用禁止ツール・機能。例: CLI、hooks、PRレビュー、外部送信、本番操作                  |
| `permission_profile`       | 必須 | read-only / workspace-write / approval-required などの権限レベル  |
| `approval_policy`          | 必須 | どの操作でユーザー承認が必要か                                           |
| `risk_classification`      | 必須 | R0〜R4 などのリスク分類。低リスク観察、高リスク副作用、禁止操作を分ける                    |
| `scope`                    | 必須 | 対象範囲。repo、ファイル種別、機能領域、会話範囲など                              |
| `out_of_scope`             | 必須 | 対象外。勝手に触らない領域                                             |
| `constraints`              | 必須 | 制約。言語、社内規約、IDE限定、ネットワーク不可、出力言語など                          |
| `prohibitions`             | 必須 | 禁止事項。推測断定、未検証成功扱い、権限外操作、ユーザー承認迂回など                        |
| `handoff_contract`         | 推奨 | 他エージェントへ渡す場合の入力・出力・要約形式                                   |
| `state_handling`           | 推奨 | 会話状態、未決事項、前提、決定事項の扱い                                      |
| `untrusted_context_policy` | 必須 | 外部URL、ログ、添付、ツール出力を「指示」ではなく「未信頼データ」として扱う方針                 |
| `observability`            | 必須 | 何を記録するか。入力、判断、出力、承認、検証、失敗理由など                             |
| `failure_report`           | 必須 | 失敗時に返す情報。原因、根拠、未検証点、次回入力、再実行条件                            |
| `examples`                 | 推奨 | 良い入力例・良い出力例・悪い出力例                                         |
| `version`                  | 必須 | テンプレートまたはエージェント定義のバージョン                                   |
| `owner`                    | 推奨 | 管理者・更新責任者                                                 |
| `review_cycle`             | 推奨 | 見直し条件。失敗再発時、規約変更時、ツール仕様変更時など                              |

## エージェント作成スキルで必ず質問する項目

| 質問カテゴリ    | 質問                              |
| --------- | ------------------------------- |
| 目的        | このエージェントは何を達成するためのものですか？        |
| 役割        | このエージェントの主担当は何ですか？              |
| 非役割       | このエージェントに絶対やらせたくないことは何ですか？      |
| 利用場面      | どんな依頼・会話・作業で起動すべきですか？           |
| 入力        | ユーザーや上位エージェントから何を受け取る必要がありますか？  |
| 出力        | 最終出力はどんな形式にしますか？                |
| 成功条件      | 何を満たせば成功ですか？                    |
| 未検証条件     | 何が確認できない場合に `unverified` としますか？ |
| 失敗条件      | 何が起きたら失敗・停止・ユーザー確認にしますか？        |
| 対象範囲      | どのファイル、領域、業務、会話範囲を対象にしますか？      |
| 対象外       | どこから先は触らない・判断しない範囲ですか？          |
| 使用可能ツール   | 使ってよいツールは何ですか？                  |
| 禁止ツール     | 使ってはいけないツールは何ですか？               |
| 権限        | 読み取り専用、編集可、承認必須のどれですか？          |
| 承認        | どの操作でユーザー承認が必要ですか？              |
| リスク       | このエージェントの操作は R0〜R4 のどれに当たりますか？  |
| 検証        | 出力後に必ず確認すべきチェックは何ですか？           |
| 他エージェント連携 | 他のエージェントへ渡す情報はありますか？            |
| 記録        | 実行時に残すべきログ・要約・判断根拠は何ですか？        |
| 例         | 理想的な入力例・出力例はありますか？              |

## スキル標準項目テンプレート

| 項目                         | 必須 | 内容                                |
| -------------------------- | -: | --------------------------------- |
| `skill_name`               | 必須 | スキル名。例: `create-agent-skill`      |
| `description`              | 必須 | 何をするスキルか。自動発火の判断材料になるため具体的に書く     |
| `when_to_use`              | 必須 | どんな依頼で使うか                         |
| `when_not_to_use`          | 必須 | 使ってはいけない場面                        |
| `goal`                     | 必須 | スキル実行後に得られる成果                     |
| `required_inputs`          | 必須 | 実行に必要な入力                          |
| `optional_inputs`          | 推奨 | あると精度が上がる入力                       |
| `clarifying_questions`     | 必須 | 入力不足時に聞く質問                        |
| `workflow`                 | 必須 | 手順。調査、質問、正規化、生成、検証、最終出力の順序        |
| `output_format`            | 必須 | 出力形式。Markdown、JSON、テンプレート、ファイル案など |
| `output_template`          | 必須 | 実際に埋めるテンプレート                      |
| `validation_checklist`     | 必須 | 出力前の自己検証チェック                      |
| `success_conditions`       | 必須 | スキル実行成功の条件                        |
| `failure_conditions`       | 必須 | スキルを停止・保留・未検証扱いにする条件              |
| `allowed_tools`            | 必須 | 使用可能なツール                          |
| `disallowed_tools`         | 必須 | 使用禁止ツール                           |
| `approval_policy`          | 必須 | ユーザー承認が必要な操作                      |
| `risk_policy`              | 必須 | 副作用、外部送信、ファイル編集、権限拡大の扱い           |
| `untrusted_context_policy` | 必須 | 外部情報や添付情報を指示として扱わない方針             |
| `observability`            | 推奨 | 記録すべき判断、入力、出力、未決事項                |
| `handoff`                  | 推奨 | 他スキル・他エージェントへ渡す形式                 |
| `examples`                 | 推奨 | 入力例、出力例、失敗例                       |
| `anti_examples`            | 推奨 | やってはいけない出力例                       |
| `references`               | 推奨 | 参照する規約、テンプレート、schema、AGENTS.md 等  |
| `version`                  | 必須 | スキル定義のバージョン                       |
| `maintenance_policy`       | 推奨 | 更新条件、退役条件、レビュー条件                  |

## `create-agent-skill` の最低限テンプレート項目

| 項目                      | 内容                                                                                                                                                                                                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `skill_name`            | `create-agent-skill`                                                                                                                                                                                                                                        |
| `description`           | ユーザーに質問しながら、ハーネス標準に準拠した custom agent 定義を作成する                                                                                                                                                                                                                |
| `trigger`               | 「エージェントを作りたい」「custom agent を作りたい」「〇〇担当エージェントを作りたい」                                                                                                                                                                                                          |
| `required_questions`    | 目的、役割、非役割、入力、出力、成功条件、検証、ツール、権限、承認、対象範囲、禁止事項                                                                                                                                                                                                                 |
| `agent_template_fields` | `agent_name`, `purpose`, `role`, `non_role`, `trigger`, `input_contract`, `output_contract`, `success_conditions`, `verification`, `allowed_tools`, `disallowed_tools`, `approval_policy`, `risk_classification`, `scope`, `out_of_scope`, `failure_report` |
| `workflow`              | 1. 目的確認 → 2. 役割確認 → 3. 入出力確認 → 4. 権限・ツール確認 → 5. 検証条件確認 → 6. 承認条件確認 → 7. agent 定義生成 → 8. 必須項目チェック                                                                                                                                                            |
| `output_format`         | Copilot custom agent 用 Markdown + YAML frontmatter 相当の定義案                                                                                                                                                                                                   |
| `validation`            | 必須項目欠落、役割の曖昧さ、出力形式未定義、ツール権限過剰、承認条件不足、未検証成功扱いを検出                                                                                                                                                                                                             |
| `default_policy`        | IDE内利用前提。CLI、hooks、PRレビュー、本番操作、外部送信はデフォルト禁止                                                                                                                                                                                                                 |
| `completion_status`     | `success` / `failure` / `unverified`                                                                                                                                                                                                                        |

| 項目                      | 内容                                                                                                                                                                                                                                  |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `skill_name`            | `create-skill-skill`                                                                                                                                                                                                                |
| `description`           | ユーザーに質問しながら、ハーネス標準に準拠した Agent Skill 定義を作成する                                                                                                                                                                                         |
| `trigger`               | 「スキルを作りたい」「SKILL.md を作りたい」「〇〇作業をスキル化したい」                                                                                                                                                                                            |
| `required_questions`    | 目的、利用場面、非利用場面、入力、出力、手順、検証、ツール、承認、リスク、例                                                                                                                                                                                              |
| `skill_template_fields` | `skill_name`, `description`, `when_to_use`, `when_not_to_use`, `required_inputs`, `workflow`, `output_format`, `validation_checklist`, `allowed_tools`, `disallowed_tools`, `approval_policy`, `risk_policy`, `examples`, `version` |
| `workflow`              | 1. 目的確認 → 2. 利用場面確認 → 3. 入出力確認 → 4. 手順化 → 5. 検証条件追加 → 6. 権限・承認条件追加 → 7. SKILL.md 案生成 → 8. 必須項目チェック                                                                                                                                  |
| `output_format`         | `SKILL.md` 用 Markdown                                                                                                                                                                                                               |

| `completion_status`     | `success` / `failure` / `unverified`                                                                                                                                                                                                |
