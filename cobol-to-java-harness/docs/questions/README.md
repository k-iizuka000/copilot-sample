# questions/ — 仕様疑義の質問票置き場

エージェントが設計書の曖昧・矛盾・不足を見つけると、ここへ質問票を起こします。
**エージェントは推測で実装しない**ルールのため、未回答の質問票がある箇所は作業が止まります。

- ファイル名: `Q-NNN_<件名>.md`
- 形式: [.github/skills/design-to-tasks/SKILL.md](../../.github/skills/design-to-tasks/SKILL.md) の「5. 疑義は質問票にする」参照

## 人間がやること

1. 「状態: 未回答」の質問票を開く
2. 「回答」欄に決定事項を記入する（必要なら設計書側も修正する）
3. 「状態」を「回答済み」に変える
4. ブロックされていたタスクの `/implement` を再実行する

回答は設計書と同じ重みを持ちます。口頭で答えず、必ずここに書き残してください。
