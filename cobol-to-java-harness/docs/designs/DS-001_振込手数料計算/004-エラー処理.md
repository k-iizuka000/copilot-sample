# 004 エラー処理

## 1. 移行方針

元COBOL（SYUT0010）はリターンコード（`WK-RETURN-CD`）でエラーを通知していた。
Java移行後は **`IllegalArgumentException`** をスローする方式とし、メッセージにエラーコードを含める。

## 2. エラー定義

| エラーコード | 元リターンコード | 発生条件 | メッセージ形式 |
| --- | --- | --- | --- |
| E001 | `91` | 振込金額が 1 未満、または 999,999,999 を超える | `[E001] 振込金額が範囲外です: {振込金額}` |
| E002 | `92` | 会員区分のコード値が `1` `2` `3` のいずれでもない | `[E002] 会員区分が不正です: {コード値}` |
| E003 | `93` | 振込先区分のコード値が `1` `2` `3` のいずれでもない | `[E003] 振込先区分が不正です: {コード値}` |

## 3. チェック順序

入力チェックは E001 → E002 → E003 の順で行い、**最初に検出したエラーのみ**を通知する（元COBOLと同一の挙動）。

## 4. 補足

- メッセージの `{…}` 部分には実際の入力値を埋め込む。
- エラー時に手数料を返却してはならない（例外スローで処理を中断する）。
