# 003 処理仕様

## 1. 処理フロー

以下の順序で処理する。順序を変えてはならない。

1. 入力チェック（[004-エラー処理.md](004-エラー処理.md) のとおり。エラー時は以降を実行しない）
2. 基本手数料の決定（本シート「2. 基本手数料の決定」）
3. 会員区分による調整（本シート「3. 会員区分による調整」）
4. 調整後の手数料を返却する

## 2. 基本手数料の決定

振込金額と振込先区分から基本手数料を決定する。

| 振込先区分 | 30,000円未満 | 30,000円以上 |
| --- | --- | --- |
| 同一支店宛（`1`） | 110円 | 220円 |
| 当行他支店宛（`2`） | 220円 | 440円 |
| 他行宛（`3`） | 550円 | 770円 |

- 金額の判定は「30,000円**以上**」を高額側とする。30,000円ちょうどは高額側を適用する。

## 3. 会員区分による調整

基本手数料に対して、会員区分ごとに以下の調整を行う。

| 会員区分 | 当行宛（同一支店・当行他支店） | 他行宛 |
| --- | --- | --- |
| 一般（`1`） | 調整なし（基本手数料のまま） | 調整なし（基本手数料のまま） |
| ゴールド（`2`） | 無料（0円） | 基本手数料の50%（端数処理は「4.」のとおり） |
| プレミアム（`3`） | 無料（0円） | 無料（0円） |

## 4. 端数処理

- ゴールド会員の他行宛手数料（基本手数料の50%）に1円単位の端数が出ることはないが、**10円未満の端数は切り捨てる**。
  - 例: 基本手数料550円 → 50%で275円 → 10円未満切り捨てで **270円**
  - 例: 基本手数料770円 → 50%で385円 → 10円未満切り捨てで **380円**
- 上記以外の箇所で端数処理は発生しない。

## 5. 計算例

| 振込金額 | 会員区分 | 振込先区分 | 手数料 | 根拠 |
| --- | --- | --- | --- | --- |
| 29,999円 | 一般 | 同一支店宛 | 110円 | 基本手数料のみ |
| 30,000円 | 一般 | 同一支店宛 | 220円 | 境界: 30,000円は「以上」側 |
| 50,000円 | 一般 | 他行宛 | 770円 | 基本手数料のみ |
| 50,000円 | ゴールド | 当行他支店宛 | 0円 | ゴールドの当行宛は無料 |
| 20,000円 | ゴールド | 他行宛 | 270円 | 550円 × 50% = 275円 → 切り捨て270円 |
| 30,000円 | ゴールド | 他行宛 | 380円 | 770円 × 50% = 385円 → 切り捨て380円 |
| 100,000円 | プレミアム | 他行宛 | 0円 | プレミアムは全宛先無料 |
