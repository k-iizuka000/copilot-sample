# 001 概要

## 1. 機能概要

| 項目 | 内容 |
| --- | --- |
| 機能ID | FEE-CALC-001 |
| 機能名 | 振込手数料計算 |
| 元COBOL資産 | SYUT0010.cbl（手数料計算サブルーチン） |
| 呼び出し元 | 振込受付処理（オンライン）、振込一括処理（バッチ） |

振込金額・会員区分・振込先区分から、振込手数料（円）を算出する。

## 2. 移行方針

- SYUT0010 の計算ロジックを、状態を持たないJavaクラスとして移行する。
- 入出力インタフェースは [002-入出力定義.md](002-入出力定義.md) のとおり。
- COBOLのリターンコード方式は、Javaでは例外方式に置き換える（[004-エラー処理.md](004-エラー処理.md)）。
- 計算結果は元COBOLと完全一致させること（端数処理の方式・適用順序を含む）。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 当行宛 | 振込先区分が「同一支店宛」または「当行他支店宛」であること |
| 他行宛 | 振込先区分が「他行宛」であること |
