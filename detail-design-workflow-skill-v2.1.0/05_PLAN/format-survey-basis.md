# 設計書フォーマット調査の反映内容

## 確認済みの構造

- 画面帳票: 改訂履歴、レイアウト、項目、項目制御、バリデーション、イベント、メッセージ、パラメータ。
- 処理機能: 改訂履歴、処理機能記述、検索要領、更新要領、項目DB対応表。
- データモデル: 正本、属性表・辞書、select、移行・作業・旧版・画像が混在する可能性。
- VIEW: VIEW一覧と、複数ブロックを持つ検索要領。
- 権限: 多段ヘッダ、非表示行、コメント、画像、VML、派生SQL列を含む可能性。

## 契約へ反映した方針

1. レイアウト、図形、画像、コメント、VMLをJ-60へ分離する。
2. 数式セルは表示値と数式文字列を両方保持する。
3. 抽出対象シート内の非表示行・列を黙って除外しない。
4. 旧版・バックアップ・作業用・派生情報を正本レコードと分離する。
5. 検索要領や権限表は親キーを保持して論理ブロック分割する。
6. プロファイル不一致時は推測せず停止する。
