# 抽出スクリプトへの移行

## 置換対象

E2J-00〜06を、プロファイルとセル位置に基づく抽出処理へ置き換える。

## 変更しない契約

- J-* JSON Schema
- Record IDとsourceRefs
- coverageとissues
- EV-01の判定基準
- M-* Markdownテンプレート
- J2M-01以降の入出力
- ゴールデンサンプル

## 移行手順

1. 代表設計書と期待JSONをゴールデンサンプルとして固定する。
2. 抽出処理が同じJ-*を出せるように実装する。
3. EV-01とSchema検証を回帰テストにする。
4. 同一入力のプロンプト版とスクリプト版を比較する。
5. 人間承認後、対象プロファイル単位で切り替える。
