# トラブルシューティング

| 症状 | 原因候補 | 対応 |
|---|---|---|
| Prompt Fileが一覧に出ない | 配置場所・拡張子 | `.github/prompts/*.prompt.md`を確認しVS Codeを再読み込み |
| Excelを読めない | ファイル文脈非対応 | I-00に従い対象シートをTSV/CSV/Markdown表へ出す |
| JSON Schemaエラー | 定義外キー、null違反、Enum違反 | 生成物を手修正せずE2Jを再実行 |
| coverageが一致しない | 空行・見出し・結合セル・非表示行の扱い | sourceUnit境界を見直しブロックを小さくする |
| EV-01がFAIL | 漏れ・追加・出典誤り | 対象E2Jへ戻る |
| EV-02がFAIL | Markdownへの欠落・追加・誤分類 | J2M-01へ戻る |
| EV-03がFAIL | タスク漏れ・巨大タスク・依存不備 | M2P-01へ戻る |
| 実装が対象外へ広がる | タスク粒度が大きい | タスクを分割し、対象ファイルと完了条件を狭める |
| テストを実行できない | IDE機能・環境制約 | 未実施として記録し、人間の実施手順へ回す |
