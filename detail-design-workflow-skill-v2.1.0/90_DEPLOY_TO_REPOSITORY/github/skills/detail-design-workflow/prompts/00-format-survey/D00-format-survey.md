# D00 設計書フォーマット調査

## 使用条件

新しい設計書種類、改訂されたテンプレート、未登録のシートを初めて扱うときだけ使用する。通常の画面・機能変換では実行しない。

## 入力

- `sourcePath`: 調査対象の設計書1冊
- `outputPath`: 調査レポート

## 実施内容

1. 正確なシート名、表示・非表示状態、使用範囲を列挙する。
2. 各シートを`extract`、`metadata`、`asset`、`reference_only`、`ignore_candidate`、`unknown`へ分類する。
3. 各論理表の正確な見出し、ヘッダ段数、繰り返し単位、主キー候補、ブロック境界を記録する。
4. 結合セル、数式、非表示行・列、コメント、drawing、media、画像、複数表の有無を記録する。
5. 既存プロファイルで処理可能か判定する。
6. 断定できない項目は確認質問として出す。

## 禁止

- 業務データを転載しない。
- 見出しやシート名を推測しない。
- 元ファイルを変更しない。
- 複数冊を一度に調査しない。

## 出力

Markdown形式で、読取状態、シート棚卸し、論理ブロック、関連キー、変換リスク、確認質問を出力する。
