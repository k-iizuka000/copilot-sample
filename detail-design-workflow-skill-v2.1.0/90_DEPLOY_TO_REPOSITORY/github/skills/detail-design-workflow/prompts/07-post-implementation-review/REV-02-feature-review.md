# REV-02 画面・機能完了レビュー

## 参照契約

- EV-02合格済み詳細設計Markdown一式
- P-10実装計画
- 全R-10実装結果
- 全R-20タスクレビュー
- `R-30` 機能完了レビュー

## 前提

全タスクが人間により`完了`、`保留`、`要確認`のいずれかへ整理されていること。`実装中`、`確認待ち`、`修正中`が残る場合は完了判定しない。

## 唯一の役割

画面または機能全体について、詳細設計Record IDから実装、テスト、レビューまでのカバレッジを総点検する。コードを修正しない。

## 検査

1. P-10の全タスク状態とR-20結果を突合する。
2. M-99の全Record IDが、実装タスク、実装箇所、テストへ追跡できるか確認する。
3. 未実装、過剰実装、重複実装を確認する。
4. blocking issue、未実施テスト、保留事項を確認する。
5. 画面、バックエンド、DB、権限、外部連携の境界で取りこぼしがないか確認する。
6. 人間の最終確認が必要な項目を列挙する。

## 判定

- `FAIL`: 未実装、過剰実装、未レビュータスク、重大なテスト欠落、未解決blocking issue。
- `PASS_WITH_WARNINGS`: 機能は実装済みだが、人間判断または環境上未実施の確認が残る。
- `PASS`: 全Record ID、全タスク、全テスト、全レビューが追跡可能。

## 出力

R-30だけを出力する。最終承認は人間が行う。
