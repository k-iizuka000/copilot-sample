# 全体計画

## 目的

標準化されたExcel設計書を、将来スクリプトへ置換可能な契約で、詳細設計と実装工程へ接続する。

## アーキテクチャ

```text
Excel設計書
  ↓ E2J-00〜06（現在はプロンプト、将来は抽出スクリプト）
J-* 出典付き構造化JSON
  ↓ EV-01
原本忠実性ゲート
  ↓ J2M-01
M-* 詳細設計Markdown
  ↓ EV-02 + 人間承認
P-10 実装計画
  ↓ EV-03 + 人間承認
IMP-01 1タスク実装
  ↓ REV-01 + 人間承認
全タスク反復
  ↓ REV-02 + 人間承認
画面・機能完了
```

## 正本

- 業務仕様の正本: 設計書
- 変換後の機械可読な正本: J-* JSON
- 人間向け詳細設計: M-* Markdown
- 実装作業の正本: 人間承認済みP-10

## 将来の置換点

スクリプト化するのは主にE2J-00〜06。J-*契約、EV-01、J2M-01、EV-02以降を維持することで、現行プロンプト検証を捨てずに自動化へ移行できる。
