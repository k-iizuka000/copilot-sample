# C-06 状態遷移と人間確認ゲート

| ゲート | 前提 | 人間が確認する内容 | 通過後 |
|---|---|---|---|
| G0 入力確定 | 対象機能と設計書がそろう | 正本、版、機能ID | JSON抽出開始 |
| G1 JSON承認 | 必要なEV-01が合格 | 漏れ、追加、警告 | Markdown生成 |
| G2 詳細設計承認 | EV-02合格 | 未確定事項、実装可否 | 実装計画生成 |
| G3 実装計画承認 | EV-03合格 | 粒度、順序、完了条件 | タスク実装 |
| G4 タスク承認 | REV-01結果 | 差分、設計一致、テスト | タスク完了 |
| G5 機能承認 | REV-02結果 | 全体カバレッジ、残存リスク | 機能完了 |

AIがゲートを自動通過させてはならない。
