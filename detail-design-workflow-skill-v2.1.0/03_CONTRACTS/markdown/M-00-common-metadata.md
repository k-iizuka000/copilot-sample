# M-00 Markdown共通契約

全Markdownは次のFront Matterを持ちます。

```yaml
---
contractId: M-10
schemaVersion: "1.0.0"
featureId: null
featureName: null
generationRunId: ""
generationStatus: complete
evaluationStatus: PASS
humanReviewStatus: not_reviewed
sourceRecordCount: 0
openIssueCount: 0
---
```

## 表記

- 不明値は`未確認`。
- 対象資料を確認して対象がない場合は`該当なし`。
- すべての仕様表に`Record ID`と`出典`を置く。
- 共通仕様を個別ファイルへ全文複製せず、共通Record IDまたはリンクを参照する。
- JSONに存在しない仕様を追加しない。
