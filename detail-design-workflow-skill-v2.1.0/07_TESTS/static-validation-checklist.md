# 静的検証チェックリスト

- [ ] 全Prompt Fileが存在し、正規プロンプトへのリンクが解決する。
- [ ] 全正規プロンプトが参照契約IDを持つ。
- [ ] 全JSON SchemaがJSONとして読み込める。
- [ ] 全Profile JSONがJSONとして読み込める。
- [ ] 主要サンプルが対応Schemaに適合する。
- [ ] 不正サンプルが期待どおり不適合になる。
- [ ] 標準手順に01〜15の順序とG0〜G5がある。
- [ ] 実装プロンプトが1タスク限定、対象外変更禁止、人間確認を要求する。
- [ ] 禁止されたプロジェクト固有略称が含まれない。
- [ ] ZIPの整合性検査が成功する。
