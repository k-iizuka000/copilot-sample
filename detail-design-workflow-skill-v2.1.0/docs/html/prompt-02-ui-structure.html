手順（原本の順序のまま）

1 指定された1シートまたは1論理ブロックだけを読む 複数シート・複数ブロックをまとめて読まない
2 profileIdのProfileでルーティングと見出しの一致を確認する 不一致なら停止する
3 表形式は原則1行を1sourceUnitとする 縦積みの表も1行単位で扱う
4 画面項目を明記どおり抽出する 項目番号・名称・属性・国際化キー・最小・最大・フォーマット・配置・備考・初期表示・一覧表示
5 パラメータ表を抽出する 表示モード・URL形式・パラメータ名・用途
6 レイアウトは明示テキストと参照関係だけを抽出する 見た目から仕様を断定しない
7 画面項目番号と表示モードを関連キーとして保持する
8 J-10 JSONだけをoutputPathへ書き込む 指定出力先以外は書き込まない

停止条件・やらないこと

禁止事項
