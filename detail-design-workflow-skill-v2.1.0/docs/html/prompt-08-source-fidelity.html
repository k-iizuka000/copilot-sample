検査順序（原本の順序のまま）

1 JSON構造、必須キー、Enum、定義外キーを確認する。 対象JSONがSchemaに適合するか
2 各recordの事実が原本に存在するか確認する。 原本との突合
3 原本にない事実が追加されていないか確認する。 追加仕様の混入がないか
4 重要な行、節、表、ブロックの欠落を確認する。 欠落の有無
5 sourceRefsのファイル、シート、位置、引用が正しいか確認する。 出典参照の正確性
6 全sourceUnitがcoverageで説明されているか確認する。 sourceUnitの網羅性
7 非表示行、数式、旧版、派生物、読取不能アセットの扱いを確認する。 特殊要素の扱い
8 不明点が確定事項になっていないか確認する。 未確認事項の断定がないか
