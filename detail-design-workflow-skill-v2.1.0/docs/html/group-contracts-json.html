このページは各プロンプトが読み書きする入力契約（I-00）とJSON中間契約（J-00〜J-90）9本の一覧です。各カードは役割・主要トップレベルキー・主な recordType/enum だけを要約したもので、全フィールドの詳細は原本スキーマを参照してください。

I-00 入力ソース契約

役割: Excelまたは入力スナップショットの形式と処理単位を定義する、JSON以外の唯一の入力契約。

  • 入力形態の優先順位: ①対象Excelを直接読み取り ②TSV/CSV/Markdown表スナップショット ③行・節ID付きテキスト ④レイアウト・図形の画像
  • 1回の処理単位: E2J-00は原則1ブック、E2J-01〜E2J-06は原則1シートまたは1論理ブロック
  • 必須識別情報: sourcePath profileId sheetName blockSelector outputPath
  • 数式は displayedValue（表示値）と formula（数式文字列）を両方保存し、Markdownへは displayedValue を使用
  • 非表示行・列は対象に含め hiddenRow/hiddenColumn に記録。画像・図形等は J-60 へ登録し、読めない内容を本文へ推測転記しない

J-00 共通定義

役割: Record ID・出典・issue・coverage等の共通型を定義するライブラリ。単体では出力されず、J-01〜J-90 の全スキーマが $ref で参照する（run/document/coverage/issues/assets/summary 等は以下の各カードで再掲しない）。

主な定義: runInfo・documentRef・sheetRef・sourceRef・issue・coverageItem・assetRef・summary・recordBase

代表的な enum: humanReviewStatus（not_reviewed/in_review/approved/rejected）・severity（blocking/warning/info）・evidenceState（explicit/derived/ambiguous）

J-01 文書マニフェスト

役割: 文書・シートの棚卸しと、後続 /02〜/07 へのルーティング計画。

主要トップレベルキー: contractId schemaVersion profileId run document status coverage issues assets summary sheets routingPlan

主な enum: routingPlan[].skillId（E2J-01〜E2J-06）と outputContract（J-10/J-11/J-20/J-30/J-40/J-60）は1対1で対応（例: E2J-01→J-10 … E2J-06→J-60）。sheets[].status は recognized/unknown/conflict。

J-10 画面構造

役割: 画面項目・表示モード・パラメータを格納。

主要トップレベルキー: contractId schemaVersion run document status coverage issues assets summary records

主な recordType: screen_item・display_mode・parameter_definition・layout_reference

J-11 画面動作

役割: 制御・バリデーション・イベント・メッセージを格納。

主要トップレベルキー: J-10と同形（records まで共通の8キー）

主な recordType: item_control・validation_rule・correlation_validation・ui_event・message_rule

J-20 処理・バッチ

役割: 処理・検索要件・更新要件・バッチ制御を格納。

主要トップレベルキー: J-10と同形（records まで共通の8キー）

主な recordType: process_section・search_requirement・update_requirement・batch_control

J-30 データ・検索・連携

役割: DB対応・データモデル・VIEW定義・外部IFを格納。

主要トップレベルキー: J-10と同形（records まで共通の8キー）

主な recordType: item_db_mapping・entity_field・attribute_definition・attribute_dictionary_entry・select_constraint・view_definition・view_query_block・external_interface

J-40 権限・共通

役割: 権限・ロール階層・共通規約を格納。

主要トップレベルキー: J-10と同形（records まで共通の8キー）

主な recordType: screen_action_permission・role_hierarchy・case_reference_permission・document_header_metadata・common_rule

J-60 アセット

役割: 画像・図形・コメント・読取状態を格納。他のJ-*と異なり records 配列を持たず、J-00 の assetRef（assets 配列）だけで構成される。

主要トップレベルキー: contractId schemaVersion run document status coverage issues assets summary

主な enum: assets[].assetType（screen_layout/image/drawing/chart/comment/vml/template/sample/unknown）・assets[].status（referenced/exported/missing/unreadable/not_required）

J-90 評価結果

役割: EV-01（/08）と EV-02（/10）の評価結果を格納。

主要トップレベルキー: contractId schemaVersion evaluatorId runId generatedAt target result checks findings metrics humanReviewStatus

主な enum: evaluatorId（EV-01/EV-02）・result（PASS/PASS_WITH_WARNINGS/FAIL）・checks[].result（PASS/WARNING/FAIL/NOT_APPLICABLE）・findings[].severity（blocking/warning/info）

判定3値の意味は group-instructions.html#evaluation を参照（複写しない）。
