詳細設計ワークフロー 解説マップ

Excel設計書を出典付きJ-* JSONへ構造化し、原本忠実性を評価してから、検証済みJSONを詳細設計Markdownへ変換する一連のPrompt群です。下のパイプライン図から各工程のページへ進めます。

パイプライン

見方: 上から下へ標準順序どおりに読む。琥珀の破線枠は人間による確認ゲート。
